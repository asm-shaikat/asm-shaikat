## 🚀 Run it locally

> Requires **Node.js 20+**

```bash
git clone https://github.com/asm-shaikat/awesome-portfolio.git
cd awesome-portfolio
npm install
npm run dev
```

Open **http://localhost:3000** and you're in.

| Command | Description |
| :-- | :-- |
| `npm run dev` | Start the dev server |
| `npm run build` | Production build + static export to `out/` |
| `npm run lint` | Lint the codebase |

> [!TIP]
> Don't run `npm run build` while the dev server is running. Both write to `.next/`, and styles will break. If that happens: stop the server, `rm -rf .next`, start again.

## 🎨 Make it yours

- **Content**: edit `src/app/(main)/data/resume.ts`. Wrap words in `**double asterisks**` to highlight them, and add `live: 'https://…'` to a project to show a link.
- **Colors**: tweak the design tokens at the top of `src/app/globals.css` (`:root` = light, `.dark` = dark).
- **Photo**: replace `public/assets/asm-shaikat.jpg`.

## ☁️ Deploy

The site is exported as static files, so any static host works (Netlify, Vercel, GitHub Pages, Cloudflare Pages).

| Setting | Value |
| :-- | :-- |
| Build command | `npm run build` |
| Publish directory | `out` |

The live site runs on **Netlify**, and GitHub Actions builds every push and pull request.
